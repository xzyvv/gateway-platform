# 行数预算基线（O-8）
#
# 约定：单文件超过 800 行即视为巨型文件，必须拆分（前端见 docs/architecture/frontend.md）。
# 本文件登记「历史上已经超限」的文件，C24 按下面的规则判：
#   - 未登记的新文件 > 800 行 → FAIL，请拆分后再提交；确属必要的才登记。
#   - 已登记文件**有硬上限**：上限 = 登记时的当前行数 + 100 行余量，超过上限 → FAIL。
#     这 100 行余量是给正常功能迭代留的预算，不是继续膨胀的空间；
#     确实需要更多，请在同一个 PR 里显式改这里的数字（基线是账本，改动会进 review，
#     不会被静默绕过）。不想拆又不想改账本，是没有第三条路的。
#   - 文件拆到 ≤800 行后，C24 会提示「可从基线移除」，请删掉对应行。
#   - 文件改名/搬迁 → 请同步改这里的路径，否则 C24 会报「基线条目失效」。
#   - 测试文件（*tests.rs / */tests/* / *.spec.ts / *.test.ts）不计入，测试本来就该长。
#
